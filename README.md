\### Pentesting Methodology - The 7 steps



Mastering the complete penetration testing stack:



1. \*\*Reconnaissance\*\* - Gathering information about the scoped target (passive \& active)
2. \*\*Scanning \& Enumeration\*\* - Identifying live systems, services and ports
3. \*\*Vulnerability Assessment\*\* - Discovering exploitable weaknesses and misconfigurations
4. \*\*Exploitation\*\* - Gaining initial access and executing attacks
5. \*\*Privilege Escalation\* - Elevating access from user to admin/root
6. \*\*Maintaining Access\*\* - Post-exploitation, persistence, and lateral movement
7. \*\*Reporting\*\* - Documenting findings, impact, and remediation reccomendations
